# Baseline-метрики

`metrics_sample_quick.json` — метрики **исходного кода** (тег `v1.0.0-baseline`),
полученные в окружении, зафиксированном в `poetry.lock`:

```bash
bash scripts/run_pipeline.sh   # sample, --quick, seed = 42
```

Файл служит эталоном для регрессионной проверки рефакторинга:

```bash
python scripts/compare_metrics.py docs/baseline/metrics_sample_quick.json <metrics.json прогона>
```

- **BKT, DKT, DKT+Optuna детерминированы**: повторный запуск даёт те же
  значения всех метрик и те же гиперпараметры Optuna, поэтому после
  рефакторинга они обязаны совпасть точно.
- **AutoML (FLAML) ограничен бюджетом времени** (15 с в быстром режиме) и
  всегда расходует его полностью: число испытаний зависит от скорости машины.
  Повторные запуски одного и того же кода на одной машине дают одинаковый
  результат, но всё, что меняет скорость (порядок загрузки библиотек, нагрузка
  на систему, другой компьютер), может сдвинуть выбранную конфигурацию. Для
  AutoML проверяется только AUC с допуском ±0.02.

| Модель | AUC | Accuracy | F1 | RMSE |
|---|---|---|---|---|
| BKT | 0.7076 | 0.7284 | 0.8205 | 0.4341 |
| DKT | 0.7764 | 0.7613 | 0.8415 | 0.4070 |
| DKT+Optuna | 0.7814 | 0.7627 | 0.8411 | 0.4048 |
| AutoML (FLAML, lgbm) | 0.7467 | 0.7501 | 0.8352 | 0.4198 |
